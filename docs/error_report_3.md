# Error Report 3

## エラー内容
`エラー: メイン・クラスnoguiを検出およびロードできませんでした`
`原因: java.lang.ClassNotFoundException: nogui`

## エラーの意味
`java` コマンドが実行される際、本来指定されるべきメインクラスや実行用 JAR ファイルが見つからなかったため、後ろに続く引数の `nogui` をクラス名として読み込もうとして失敗しています。これは、NeoForge の実行に必要なライブラリ群（`libraries` ディレクトリ等）が、サーバーの実行ディレクトリ（`data/`）に存在しないことが主な原因です。

## 修正計画
### 何を
`flake.nix` の起動スクリプトにおいて、`serverPkg` に含まれるライブラリ群を `data/` ディレクトリにリンクする処理を追加します。

### 何故
NeoForge 1.21.1 は非常に多くのライブラリ（jar）に依存しており、それらが実行時のカレントディレクトリ以下の `libraries` フォルダなどに配置されている必要があるためです。

### どのように
起動スクリプト (`run-minecraft-server`) の中で、Mod と同様に `serverPkg` 内のライブラリや必要なファイルを `data/` フォルダへシンボリックリンクする処理を追加します。また、`nogui` 引数を適切に処理します。

```nix
          # 修正案（抜粋）
          # パッケージ内の全ファイルを data フォルダにリンク（ただし既存のフォルダは除く）
          lndir -silent ${serverPkg}/lib/minecraft $DATA_DIR
```
※ `lndir` が使えない場合は `ln -s` で `libraries` 等を個別にリンクします。

## 承認のお願い
この修正（ライブラリのリンク処理の追加）を行ってよろしいでしょうか？承認いただければ `flake.nix` を更新いたします。
